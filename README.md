# Simple Interest Calculator

This repository contains a Bash script (`simple-interest.sh`) and project documentation for calculating simple interest based on user input.

## Overview
The Simple Interest Calculator computes simple interest using the principal amount, annual rate of interest, and time period.

## Formula
Simple Interest = (Principal * Rate * Time) / 100

- **Principal:** The initial amount of money.
- **Rate of Interest:** The annual interest rate (in percentage).
- **Time Period:** The duration of time (in years).

## Usage
Run the `simple-interest.sh` script and enter the principal, rate of interest, and time period when prompted.
